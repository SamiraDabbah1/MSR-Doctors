# MSR Doctors

موقع خدمات طبية منزلية باللغة العبرية.

## ترتيب الملفات

- `frontend/`: صفحة الموقع والتصميم والصور — React + Vite.
- `backend/`: استقبال نموذج التواصل وإرسال البريد — Node.js + Express.
- `tests/`: اختبارات نموذج التواصل.
- `.gitignore`: يستثني ملفات الإعدادات الخاصة والملفات الناتجة محليًا عند استعمال Git.

## تشغيل محلي

داخل `frontend`:

```sh
npm.cmd install
npm.cmd run dev
```

داخل `backend`، انسخي `.env.example` إلى `.env` وضعي إعدادات البريد عندك فقط، ثم:

```sh
npm.cmd install
npm.cmd run dev
```

لتشغيل الاختبارات، من المجلد الرئيسي:

```sh
node --test tests/contact.test.js
```

## الرفع والنشر

ارفعي محتويات هذا المجلد كاملة إلى مستودع واحد في GitHub مع الحفاظ على المجلدات كما هي. الملفات الموجودة هنا خالية من ملف `.env` ومن مجلدات `node_modules` و`dist`.
ملف `backend/.env.example` هو نموذج إعدادات فارغ من كلمات السر ويمكن رفعه.
رفع الكود إلى GitHub خطوة تحضيرية؛ تشغيل الموقع للعامة يحتاج نشر الـFrontend والـBackend وربط مسار `/api` بالـBackend. إعدادات Vite الحالية توجه `/api` للـBackend المحلي أثناء التطوير فقط.
